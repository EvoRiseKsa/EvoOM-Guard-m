# v4.6.0 Marketplace/README erratum

This is a post-publication documentation correction. It is **not** a release
ledger, replacement release, or amendment to the immutable `v4.6.0` tag.

## What is incorrect

The README bytes frozen at tag `v4.6.0` were necessarily created before the
post-publication signed ledger could be committed to protected `main`. Those
bytes therefore describe source `4.6.0` as a release candidate and direct some
consumer examples and asset downloads to the previous `v4.5.0` release.

GitHub Marketplace identifies `v4.6.0` as the latest published Action version.
A version-selected or tag-scoped README view can nevertheless preserve the
pre-publication text above. That presentation is stale after publication and
ledger completion.

## Correct current status

The immutable `v4.6.0` release is the latest supported consumer release at
commit `d65f25f386fe6f4646ea8dd3cbbe1d5d889f73d4`. Its canonical signed record is
[`evidence/release-ledgers/v4.6.0/RELEASE_LEDGER.json`](../../evidence/release-ledgers/v4.6.0/RELEASE_LEDGER.json).
Current consumer instructions should pin `v4.6.0` or that full commit and use
the three `v4.6.0` release assets named by the ledger.

## Integrity boundary

The tag, release, assets, checksums, attestations, and signed ledger remain
unchanged. This erratum corrects documentation only; it does not add evidence,
change release authority, claim independent review, or claim completion of the
separate publication-key retirement operation.
